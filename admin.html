⚡ Vercel Cloud Deployment & Persistent Database Guide

1 Vercel Serverless Function

All backend endpoints run on Vercel Serverless Functions (`api/index.js`). Form submissions from sparkpointinfotech.com automatically reach the backend.

2 Persistent Cloud DB (Supabase / Neon)

To persist data permanently on Vercel across function restarts, add a free PostgreSQL database URL in Vercel project environment variables:

DATABASE_URL = postgres://user:pass@ep-xyz.neon.tech/neondb?sslmode=require
3 Custom Admin Security Password

Set custom password in Vercel Environment Variables:

ADMIN_PASSWORD = YourSecurePassword2026!
